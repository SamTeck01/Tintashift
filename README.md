# Tintashift

Landing page and storefront for Tintashift colour-shifting smart press-on nails.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

- `lib/shades.ts`: shade names, colours and price
- `components/Hero.tsx`: opening section shade switcher and "Try it on" view
- `components/Sections.tsx`: shades grid, skin-tone try-on, technology, how-to-wear, outfits, newsletter, footer
- `public/img`, `public/vid`: AI-generated shade images and clips from Tintashift's own videos
